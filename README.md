# Sala de Fuga · Revisão ENEM

Escape room de Matemática para as turmas **M21 e M22** do Curso G9, com o Prof. Mateus Bibiano.

**Acesse:** https://mateusbibiano.github.io/sala-de-fuga-enem/

- 4 salas, em qualquer ordem: Porcentagem, Razão e Proporção, Estatística e Geometria Básica.
- Cada objeto da sala guarda questões do ENEM; resolvidas, revelam um número do cadeado.
- Cronômetro com penalidades (erro, dica e código errado), estrelas, pontos e um cofre mestre.
- O progresso fica no navegador do aluno e é enviado ao professor para o ranking da turma.
